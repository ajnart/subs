# Subs

## Agent skills

### Issue tracker

Issues and specs are Git-tracked Markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the default triage roles in issue `Status:` lines. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: root `GLOSSARY.md` and `docs/adr/`. Before exploring the codebase, read `docs/agents/domain.md`.

### Rewrite execution

For rewrite scope, delegated decisions, dependencies, or completion evidence, read `.scratch/rewrite/spec.md` and `.scratch/rewrite/map.md`.

### Architecture and sources

Before changing framework, persistence, auth, or design-system boundaries, read `docs/agents/architecture.md` and the relevant ADR.

### Repository-local skills

For skill selection, provenance, licensing, restore, or updates, read `docs/agents/skills.md`. Checked-in `.agents/skills/` contains real copies; preserve upstream notices.
