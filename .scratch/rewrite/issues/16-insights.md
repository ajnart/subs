# 16 — Spending and Category insights

Status: ready-for-agent
Progress: open
Type: task
Blocked by: 12, 14

## Outcome

Explain projected spending composition with accessible, truthful visualizations.

## Acceptance criteria

- Category spending breakdown and major commitments derive from the same active-only normalization as the summary.
- Mixed currencies retain separate groups or disclose actual comparable conversion; unavailable FX never becomes an invented total.
- Charts use Bold Wikipedia chart tokens, meaningful legends, and an accessible text/table alternative.
- Any period view is labeled as a projection from current commitments, not historical actual spending.
- Empty categories, unknown Category fallback, zero-cost records, and failed loads have useful states.
- Insight scope is clear and changing display controls does not mutate Subscriptions.

## Comments

Historical payment reporting is not part of this release.
